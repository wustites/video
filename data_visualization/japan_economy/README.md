# 日本 1985—2026 経済指標の変化

Remotionで制作した日本語の縦型データビジュアライゼーション。出力は1080×1920です。全画面でGoogle Fontsの **Noto Sans JP** をネットワークフォントとして使用し、Remotionのレンダリング前に読み込みを待機します。

1985年から2026年までの日本経済を、バブルと崩壊、失われた30年、円の大きな変動、人口減少と構造的な回復という4つの章で描きます。画面には以下の指標を収録しています。

- 住宅地価格指数（1985 = 100）
- 失業率
- ドル円・年平均レート
- 出生数
- 名目GDP（兆ドル）
- 日経平均株価
- 1985年プラザ合意、1991年バブル崩壊、1997年アジア通貨危機、2008年世界金融危機、2011年東日本大震災、2013年アベノミクス、2020年新型コロナ、2022年円安、2024年出生数過去最少などのイベント

## 実行

```bash
npm install
npm run dev
npm run voiceover
npm run check
npm run render:draft
npm run render
```

## 旁白

日本語ナレーションは `public/voiceover/narration.ja.txt` に段落ごとに分割して収録しています。`npm run voiceover`（Edge TTS / ja-JP-NanamiNeural）が各段落の MP3 を生成し、実測時間から `segment-durations.json` を書き出します。シーンの開始・終了時刻と総尺は [`src/timing.ts`](src/timing.ts) がこの実測時間から自動算出するため、ナレーションを修正したら必ず再生成してください。

## データの扱い

データは [`src/data.ts`](src/data.ts) にあります。映像でトレンドを見せるため、年次のアンカー系列を線で結んでいます。住宅地価格指数は基準年をそろえたトレンド表示です。2025—2026年は暫定値 / 推計値であり、最終的な公的統計の代替ではありません。正式版を制作する場合は、`src/data.ts` の `values` と `SOURCES` を置き換えてください。

参照元：総務省統計局、厚生労働省「人口動態統計」、国土交通省の地価公示 / 不動産価格指数、World Bank / FREDのGDP・為替系列、日本取引所グループ / 日本経済新聞社の日経平均株価。
