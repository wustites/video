2026年10月27日，OpenAI 发布了 GPT-6.1 Terra。这是 GPT-6 家族里的中档模型，主打两件事：看懂屏幕、操作电脑，并且又快又便宜。

先看价格。API 标准价每百万输入 token 一美元，输出五美元，比上一代 GPT-5.6 Terra 便宜一半。OpenAI 说，它能做到和旗舰 GPT-6 Astra 相当的水平，每 token 价格却只有十分之一；完成任务的平均速度，比 GPT-6 Astra 和 GPT-6.1 Sol 快三倍以上。

衡量智能体办公能力的 Agents' Last Exam 上，中等推理强度下，Terra 拿到百分之五十七点六，比 GPT-5.6 Terra 高出十五个百分点，和 GPT-6 Astra 持平。但每个任务的成本只要零点二九美元，GPT-6 Astra 则要四点八二美元。

它的核心能力是电脑操作和视觉推理：读懂屏幕上的内容，在多个应用之间点击、输入，完成填表、处理发票、解读工程图纸这样的日常工作。在 OSWorld 2.1 上，它用中等推理强度就追平了上一代的最好成绩；在视觉推理评测 MMMU-Pro 上，也接近 GPT-6 Astra 和 GPT-6.1 Sol。

事实准确性大幅提升。在 OpenAI 专门设计来诱发错误的内部测试中，低推理强度下的错误率从百分之五十三点六降到十六点七；开到最高推理强度，错误率只有百分之四点三。第三方 Artificial Analysis 的测试也显示，它的幻觉率从百分之八十八降到三十八。

编程同样进步明显。在 Terminal-Bench 4.0 上，最高推理强度的成绩从百分之二十一点五提升到五十点三，翻了一倍还多。不过 OpenAI 也坦言，最复杂的编程任务，仍然推荐使用 GPT-6.1 Sol 或 GPT-6 Astra。

安全方面，OpenAI 表示，按照它的准备度框架，Terra 的网络安全能力已经达到"关键"级别，因此沿用了为 GPT-6 Astra 打造的全部防护措施，同时对提示词注入的抵抗力也更强。

目前，GPT-6.1 Terra 已向 Plus、Pro、企业版和教育版用户开放，可以在 ChatGPT Work 和 Codex 中使用，开发者也能通过 API 调用。前沿能力，正在以十分之一的价格，走进每个人的日常工作。
