2026年10月24日，月之暗面发布了 Kimi K3.1 Pro。这是 K3.1 系列的第一款模型，也是他们迄今为止最强的三万亿参数级开源权重模型。

它采用混合专家架构，总参数两点八万亿，每次激活一千零四十亿，支持一百万 token 的上下文，并且原生多模态。同时发布的 Highspeed 版本，速度是 Pro 的两到三倍。

在编程、智能体和知识类评测上，K3.1 Pro 已经追平或逼近最强的闭源模型。在 Terminal-Bench 4.0 上，它拿到百分之六十五点七，超过 GPT-6 Astra 的五十八点二，仅略低于 Claude Opus 5.5 的六十六点四。在内部的长程编程评测上，也从 K3 的五十五点九五提升到六十一点二。

它能完成整个项目级别的编程，在 Unity、Unreal 和 Godot 中直接做出完整的游戏。在一项内部测试中，它基于一个人体解剖模型，其中有含软骨在内的两百九十六个骨骼组件、四百零二个肌肉组件，搭建行走模拟器，自己排查出肩部肌肉力臂的三十六处计算错误，让虚拟人从几秒就摔倒，变成连续行走十一点二秒。

3D 建模是另一大亮点。在 BenchCAD 上，它借助工具拿到百分之九十二点七，接近 Claude Opus 5.5 和 GPT-6 Astra。它不需要 MCP 连接器，就能直接编写脚本驱动 Blender 和 CAD 软件，做出机械零件、建筑模型和定制家具这样的参数化模型。

金融场景更加可靠。它在 OfficeQA Pro v2 上取得六十四点四的最好成绩；财务建模提升七点二分，金融研究提升十一点六分，商业运营达到 K3 的约四点二倍。最关键的是幻觉：在高难度事实测试中，陈述级幻觉率从百分之二十三点四降到八点三，降幅约百分之六十五。

安全方面，团队在训练中主动剔除了网络攻防相关数据。在漏洞利用评测上，未做处理的版本能解决百分之九十点五的题目，最终发布的模型降到八十一，并且仍落后于已公开三个月以上的前沿闭源模型。

目前，K3.1 Pro 和 Highspeed 已经上线 Kimi 网页与应用、Kimi Work、Kimi Code 和开放平台 API，完整权重将在十一月四日前开源。开源模型和闭源前沿的距离，正在被再一次拉近。
