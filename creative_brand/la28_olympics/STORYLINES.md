# 备选方案

## A. 同一座体育场，第三次开幕（采用）

洛杉矶纪念体育场大门是第 0 帧：1932、1984 白字，2028 橙字。上半屏 1932 开幕式、下半屏 1984 田径赛场划入；航拍里 2028 第三次开幕，和伦敦、巴黎并列；然后换到 SoFi、海滩、夜景讲新变化，最后回到体育场柱廊收尾。选它，因为一座真实建筑把“第三次”讲得最直观。

- 开头两秒：体育场大门上的“1932”，第 2 拍升起 1984，第 4 拍砸下橙色 2028。
- 节拍：三个年份 → 1932 / 1984 → 7.14 第三次、三城并列 → （鼓点进入）SoFi 同晚开幕、改游泳 → +5 个新项目 → 351 小项 / 女子名额更多 → 7.14—7.30 洛杉矶见。
- 视觉：全屏真实照片 + 顶部暗色渐变，Noto Sans SC，加州日落橙只给 2028、数字和重点。
- 声音：只有配乐（Mixkit “Karma”，129 BPM），无旁白。1.0.0 版曾用 edge-tts 中文旁白 + 字幕，约 60 秒。

## B. 一座城就是赛场

地图飞行：从市中心出发，沿高速飞过 SoFi、威尼斯海滩、长滩、帕萨迪纳，每一站一个比赛项目。场馆分配多次调整，需要逐个核实，素材成本高。

## C. 五个新项目

大字排版：腰旗橄榄球、壁球、板球、长曲棍球、棒垒球，每项一屏，切在节奏上，结尾落到 351 个小项。节奏强，但缺少洛杉矶这个地方。
