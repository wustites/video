# 山东本科院校 · Remotion 竖屏版

1080×1920 竖屏视频：真实山东省地图整层常驻（DataV GeoAtlas 省界与 16 地级市分区、地级市行政中心标记），相机按场景平移缩放聚焦；16 地市逐个列举，每个地市最多 5 所代表性本科院校；中文 Edge TTS 旁白。

```bash
npm install
npm run voiceover   # 重新生成中文旁白与分段时长（联网调用 edge-tts）
npm run check
npm run dev
npm run render:draft
```

旁白声音：`zh-CN-XiaoxiaoNeural`。具体招生计划、专业组和录取要求请以当年官方招生章程为准。

## 院校名单与口径

`src/data.ts` 中每个地市最多收录 5 所本科层次普通高校（含民办院校与校区），按“代表性”选取，**不是排名**：

- 收录范围：所在地市内的本科层次普通高等学校；同一所学校的不同校区按所在地市分别计入（例如山东大学记入济南，山东大学（威海）记入威海；山东医药大学主校区记入烟台，滨州校区记入滨州）。
- 校名口径：使用学校当前名称，如山东航空学院（原滨州学院）、山东第二医科大学（原潍坊医学院）、山东医药大学（原滨州医学院）。
- 校名核验时间：2026-09。名单不反映招生批次、专业设置或办学水平，报考请核对当年官方招生章程。
- 全片共 39 条条目，覆盖 36 所高校；山东大学、曲阜师范大学、山东医药大学因跨地市办学分别在不同地市各计一条。
- 口径不写进画面与旁白（片尾卡片也已删除），只保留在本 README、`src/data.ts` 注释与院校名单说明里；招生相关的免责说明见 README 开头。

修改 `src/data.ts` 的院校名单时，必须同步修改 `public/voiceover/narration.zh.txt` 的对应段落，然后重新运行 `npm run voiceover`。旁白段落顺序必须与 `intro`、16 个地市（行政区划代码顺序）的场景顺序一致，否则画面与旁白会错位。

## 时间轴与旁白

全片共 17 个场景：片头 `intro` 加 16 个地市，没有总览旁白与结尾旁白。场景起止时间由旁白分段的实测时长推导，见 `src/timing.ts` 与 `src/scenes.ts`：`npm run voiceover` 写入 `public/voiceover/segment-durations.json`，场景窗口按帧取整且首尾相接（上一场景结束帧即下一场景开始帧）。底板与地图是常驻图层，边界处只有文字交接：上一场景的文字在 0.2s 内退场，下一场景的文字延后 0.12s、在 0.35s 内上浮淡入，因此不会有空画面，也不会两段文字长时间叠在一起。旁白结束后 0.5s 开始 2.5s 黑场淡出，成片总时长为 `ceil(旁白结束 + 3.8)` 秒（当前 96 秒）。

## 版面与地图相机

画面分两层：地图铺满整帧（上带 `MAP_BAND_BOTTOM` = 1120px），底部 800px 是固定高度的信息卡。竖屏空间都用在大字号地市名、院校清单和大幅地图上，内容短的地市也不会让版面塌下去。

地图不是每个场景各画一张，而是一层持续存在的真实地图加一台相机（`src/mapCamera.ts`，纯函数，无 Remotion 依赖）：

| 场景 | 相机 |
| --- | --- |
| 片头 `intro` | 整省视图（viewBox 全宽 1000 单位），并铺开显示 16 个地市名 |
| 各地市场景 | 该市真实边界包围盒，长边留 18% 余量，并对可视带高宽比收边，最大放大 6 倍 |
| 地市↔地市切换 | 1.5s 飞行：中心走二次贝塞尔并在中段拱起视野，飞行途中两侧地区同时可见 |
| 片头↔首个地市 | 宽度在对数空间单调推拉，不会为了“同时装下”而甩镜头 |
| 场景内部 | 旁白区间内极缓慢推近 5%，静止镜头也有呼吸感 |

所有文字都走 `src/fonts.ts` 加载的 Noto Sans SC：字体只应用在 composition 根节点（`ShandongAtlas` 的 `AbsoluteFill`）。渲染镜像里没有中文字体，任何漏掉字体继承的图层（例如后来新加的覆盖层）在地图上会整层文字空白，本地却看不出来——改版后请按 `npm run render:draft` 抽查一帧确认。

相机映射到画面：`svg` 的 `viewBox` 直接跟随相机矩形，定点标记与文字是 HTML 覆盖层，按同一映射换算成像素，描边宽度按 `1/scale` 折算，所以放大后线宽与字号保持不变。聚焦地市的名字牌贴在行政中心旁并随相机淡入淡出，只有全省视图才铺开显示全部 16 个地市名（并在缩放到地市时淡出）。

## 地图数据

地图不是手绘示意，而是基于自然资源部行政区划边界（阿里 DataV GeoAtlas，adcode 370000）生成：

| 文件 | 内容 |
| --- | --- |
| `data/shandong-370000.json` | 山东省省界（MultiPolygon，含岛屿） |
| `data/shandong-370000-full.json` | 16 个地级市边界 |
| `scripts/gen_geo.py` | 简化（Douglas-Peucker）→ 等距圆柱投影（含纬度余弦修正）→ 行政中心标记校验 → 标签防重叠排版 → 生成数据 |
| `src/shandongGeo.ts` | 生成结果：viewBox 坐标系内的省界/地市 path、标记点、标签点、地市包围盒（相机聚焦窗口） |

修改或更新边界后重新生成：

```bash
python3 scripts/gen_geo.py
npm run check
```

生成脚本内置校验：每个地市行政中心点必须落在该市（简化后）边界内，否则回退到多边形质心；全部标签两两不重叠、不压住任何标记点。地市包围盒同样由该脚本输出，相机聚焦窗口即由它推导，边界更新后无需手工调整。
