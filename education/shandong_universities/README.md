# 山东本科院校 · Remotion 竖屏版

1080×1920 竖屏视频：真实山东省地图速览（DataV GeoAtlas 省界与 16 地级市分区、地级市行政中心标记）、16 地市快速列举、每个地市最多 5 所代表性本科院校、中文 Edge TTS 旁白。

```bash
npm install
npm run voiceover   # 重新生成中文旁白与分段时长（联网调用 edge-tts）
npm run check
npm run dev
npm run render:draft
```

旁白声音：`zh-CN-XiaoxiaoNeural`。具体招生计划、专业组和录取要求请以当年官方招生章程为准。

## 院校名单与口径

`src/data.ts` 中每个地市最多收录 5 所本科层次普通高校（含民办院校与校区），按“代表性”选取，**不是排名**：

- 收录范围：所在地市内的本科层次普通高等学校；同一所学校的不同校区按所在地市分别计入（例如山东大学记入济南，山东大学（威海）记入威海；山东医药大学主校区记入烟台，滨州校区记入滨州）。
- 校名口径：使用学校当前名称，如山东航空学院（原滨州学院）、山东第二医科大学（原潍坊医学院）、山东医药大学（原滨州医学院）。
- 校名核验时间：2026-09。名单不反映招生批次、专业设置或办学水平，报考请核对当年官方招生章程。
- 全片共 39 条条目，覆盖 36 所高校；山东大学、曲阜师范大学、山东医药大学因跨地市办学分别在不同地市各计一条。

修改 `src/data.ts` 的院校名单时，必须同步修改 `public/voiceover/narration.zh.txt` 的对应段落，然后重新运行 `npm run voiceover`。旁白段落顺序必须与 `intro`、`overview`、16 个地市（行政区划代码顺序）、`outro` 的场景顺序一致，否则画面与旁白会错位。

## 时间轴与旁白

场景起止时间由旁白分段的实测时长推导，见 `src/timing.ts` 与 `src/scenes.ts`：`npm run voiceover` 写入 `public/voiceover/segment-durations.json`，场景窗口按帧取整且首尾相接（上一场景结束帧即下一场景开始帧），每个场景在旁白区间内完全不透明；边界处上一场景在 0.5s 内淡出，下一场景内容同时淡入，两者交叠，因此切点不会出现空画面。旁白结束后 0.5s 开始 2.5s 黑场淡出，成片总时长为 `ceil(旁白结束 + 3.8)` 秒（当前 112 秒）。

## 地图数据

地图不是手绘示意，而是基于自然资源部行政区划边界（阿里 DataV GeoAtlas，adcode 370000）生成：

| 文件 | 内容 |
| --- | --- |
| `data/shandong-370000.json` | 山东省省界（MultiPolygon，含岛屿） |
| `data/shandong-370000-full.json` | 16 个地级市边界 |
| `scripts/gen_geo.py` | 简化（Douglas-Peucker）→ 等距圆柱投影（含纬度余弦修正）→ 行政中心标记校验 → 标签防重叠排版 → 生成数据 |
| `src/shandongGeo.ts` | 生成结果：viewBox 坐标系内的省界/地市 path、标记点、标签点 |

修改或更新边界后重新生成：

```bash
python3 scripts/gen_geo.py
npm run check
```

生成脚本内置校验：每个地市行政中心点必须落在该市（简化后）边界内，否则回退到多边形质心；全部标签两两不重叠、不压住任何标记点。
