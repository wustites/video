# 备选方案

## A. 从 216 人到 50648 人（采用）

一个数字贯穿全片：开场第 0 帧就是 1983 年首届新生 216 人，结尾滚到今天的 50648 人。中间每个场景一张真实校园照片，年份大字随时间推进：援建、迁入粤海、全国第一、腾讯创始人、丽湖校区、高水平大学。选它，因为陌生人也能记住一个数字的变化。

- 开头两秒：粤海校区南门照片，红色大字“216 人”，旁白“一九八三年九月，深圳大学第一次开学”。
- 节拍：216 → 特区同步起步与三校援建 → 1984 迁入粤海 → 全国第一 → 腾讯 4/5 → 丽湖 2017 / 高水平 2018 → 50648。
- 视觉：全屏真实照片 + 顶部暗色渐变，Noto Sans SC，深大红只用于数字和强调。
- 声音：edge-tts 旁白，无配乐。

## B. 一条深南大道到丽湖

地图飞行：从 1983 年的后海海边出发，沿南山一路飞到西丽丽湖，每个站点是一段校史。需要历史地图与卫星影像，素材成本高。

## C. 一张“第一”清单

大字排版：毕业生不包分配、聘任制、学分制、勤工俭学、学生法庭……每个“第一”一屏，切在旁白节奏上，结尾落到今天的深大。信息密但缺少人和地方。
