# 日本 1985—2026 经济指标变化

一个基于 Remotion 的中文竖屏数据可视化视频项目，默认输出 1080×1920。

视频按时间线讲述日本经济的四个阶段：泡沫与破裂、长期低增长、日元的大幅摆动，以及人口收缩与结构性复苏。画面包含：

- 住宅地价格指数（1985 = 100）
- 失业率
- 美元兑日元年均汇率
- 出生人口
- 名义 GDP（万亿美元）
- 1985 广场协议、1991 泡沫破裂、1997 亚洲金融危机、2008 全球金融危机、2011 东日本大地震、2013 安倍经济学、2020 新冠疫情、2022 日元贬值、2024 出生人口新低等事件标记

## 运行

```bash
npm install
npm run dev
npm run check
npm run render:draft
npm run render
```

## 数据口径

数据保存在 [`src/data.ts`](src/data.ts)，采用适合视频叙事的年度锚点序列并在图表中连线。住宅地价格指数是统一基准后的趋势展示；2025—2026 标记为暂估 / 预测，不能替代最终官方统计值。要制作正式研究版，直接替换 `src/data.ts` 中的 `values` 和 `SOURCES` 即可。

参考口径：日本总务省统计局、日本厚生劳动省《人口动态统计》、日本国土交通省地价公示 / 不动产价格指数、World Bank 与 FRED 的 GDP / 汇率序列。
